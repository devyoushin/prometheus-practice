# AI 작업 지침

이 디렉터리는 Prometheus 문서를 다룰 때 사용하는 AI 작업 지침을 모은다.

## 문서 목록

| 문서 | 용도 |
|------|------|
| `doc-writer.md` | 문서 작성 기준 |
| `exporter-advisor.md` | exporter 구성과 연동 기준 |
| `alerting-designer.md` | 알림 규칙과 라우팅 설계 |
| `troubleshooter.md` | 문제 해결 절차 |

## 언제 보나

- 새 문서 초안을 쓸 때 `doc-writer.md`
- 수집기/Exporter를 추가할 때 `exporter-advisor.md`
- 경보 규칙을 설계할 때 `alerting-designer.md`
- 장애 분석이나 재현이 필요할 때 `troubleshooter.md`
