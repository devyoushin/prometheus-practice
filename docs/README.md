| `service-monitor-guide.md` | ServiceMonitor와 PodMonitor |
| `exporters-guide.md` | exporter 구성과 활용 |

| `storage-guide.md`, `remote-write-guide.md` | TSDB, 보존 정책, 원격 저장소 |

| `rules/` | 문서 작성 및 운영 규칙 |
| `templates/` | 서비스 문서, 런북, 장애 보고서 템플릿 |
